# Персональне й національне в голодомороцентричному ліро-епосі

Вебпрезентація дослідження О. В. Смирнова: титульний і три змістові слайди.

## Онлайн-презентація

[Відкрити презентацію на GitHub Pages](https://alex-smirnoff.github.io/literature-history-presentation/).

## Перегляд

Відкрийте `Presentation.html` у браузері. Це автономний файл із вбудованими шрифтами та зображеннями, який працює без інтернету.

Керування: стрілки, пробіл, Page Up / Page Down. Home відкриває перший слайд, End — останній. Також доступні прокручування й натискання на слайд.

## Редагування

- `index.html` — текст і структура слайдів.
- `styles.css` — оформлення вихідного шаблону.
- `research.css` — компонування цієї презентації, яскравість фонів і прозорість оверлею.
- `script.js` — навігація, масштабування та зміна фонових зображень.
- `assets/scene/` і `fonts/` — локальні зображення та шрифти.

Після редагування можна відкрити `index.html` або перебудувати автономний файл командою:

```sh
python scripts/build_standalone.py
```

Скрипт використовує лише стандартну бібліотеку Python 3.
